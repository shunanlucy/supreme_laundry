## 🚀 Getting Started

### Local Preview
Simply open `index.html` in any modern web browser or serve with a lightweight static server:
```bash
# Using Node.js http-server
npx http-server -p 8080

# Or Python 3
python -m http.server 8080
```
- **Customer Booking Portal:** `http://127.0.0.1:8080/index.html`
- **Admin Management Portal:** `http://127.0.0.1:8080/admin/index.html`
